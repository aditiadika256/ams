# User Guide: Panduan Tampilan Antarmuka Panel Admin AMS

Panduan ini ditujukan bagi Administrator, Mentor, dan Operator dalam menggunakan antarmuka panel administrasi AMS dengan fitur palet warna dinamis, tema gelap/terang, dan kemudahan akses mobile.

---

## 1. Tampilan Modern & Tema Fleksibel

Panel Admin AMS dirancang dengan antarmuka modern semi-transparan (*glassmorphism*) yang nyaman dilihat baik di siang maupun malam hari:

- **Mode Terang (Light Mode)**: Menggunakan kontras tinggi untuk seluruh teks, label, dan lencana status sehingga mudah dibaca di lingkungan ruangan terang tanpa silau.
- **Mode Gelap (Dark Mode)**: Mengurangi kelelahan mata saat bekerja di malam hari dengan latar belakang gelap lembut dan aksen warna neon halus.
- **Peralihan Tema**: Klik ikon matahari/bulan pada bilah atas (*top bar*) untuk beralih mode kapan saja.
- **Dukungan Palet Warna**: Warna aksen utama (tombol tindakan, tautan aktif, tab aktif) dapat disesuaikan melalui menu **Color Palette Manager** dan akan langsung diterapkan ke seluruh form administrasi.

---

## 2. Navigasi & Tata Letak Responsif

Antarmuka panel admin kini dioptimalkan sepenuhnya untuk berbagai ukuran layar (Desktop, Tablet, dan Ponsel):

1. **Bilah Samping (Sidebar)**:
   - Pada layar desktop, sidebar dapat diperlebar atau diciutkan sesuai kebutuhan area kerja.
   - Pada layar ponsel, sidebar dapat dibuka dengan tombol menu di kiri atas dan ditutup cukup dengan menyentuh area luar (*backdrop*).
2. **Formulir & Jendela Input (Dialog Modal)**:
   - Kolom isian formulir otomatis menyesuaikan menjadi 1 kolom vertikal saat dibuka pada ponsel, mencegah tampilan terpotong.
   - Ukuran tombol tindakan memiliki tinggi minimum ergonomis agar mudah ditekan menggunakan jempol pada layar sentuh.
   - Tombol "Batal" dan "Simpan" tersusun rapi di bagian bawah form dan tidak saling tumpang tindih.

---

## 3. Arti Lencana & Status Warna

Untuk memudahkan identifikasi data secara visual:

| Status | Tampilan Warna | Keterangan |
| :--- | :--- | :--- |
| **Aktif / Lunas / Selesai** | Hijau Zamrud (*Emerald*) | Sesi ujian aktif, transaksi lunas, program terbit, atau lolos syarat. |
| **Peringatan / Menunggu** | Kuning Jingga (*Amber*) | Perlu tinjauan admin, peringatan integritas CBT, atau status draft. |
| **Info / Dijeda** | Biru Laut (*Blue*) | Sesi dihentikan sementara atau informasi penjadwalan. |
| **Gagal / Dibatalkan / Ditolak** | Merah Mawar (*Destructive*) | Pembayaran tertahan, siswa didiskualifikasi, atau soal dianulir. |
| **Arsip / Roadmap** | Abu-abu Netral (*Muted*) | Data historis yang diarsipkan atau fitur yang masih dalam tahap pengembangan. |

---

## 4. Tips Penggunaan

- **Pencarian Cepat**: Tekan tombol `Ctrl + K` (atau gunakan kolom cari di header) untuk mencari menu atau data secara instan.
- **Ekspor Laporan**: Pada menu Keuangan (*Finance*) dan Hasil Ujian (*Monitor Assessment*), tombol **Export CSV / PDF** tersedia di kanan atas tabel untuk mengunduh rekapitulasi data.
- **Multi-Tab**: Buka beberapa modul sekaligus dalam bentuk tab di bagian atas layar untuk kemudahan multitasking tanpa kehilangan progres formulir yang sedang diisi.
