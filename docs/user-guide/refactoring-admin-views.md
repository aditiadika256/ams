# User Guide: Panduan Manajemen Data pada Panel Admin

Panduan ini ditujukan bagi Administrator sistem Arkanin untuk memahami dan mengoperasikan fitur pengelolaan data (Tambah, Ubah, Hapus) pada panel administrasi.

## Modul Administrasi yang Didukung
Seluruh modul utama di bawah ini telah dimigrasikan ke antarmuka dialog interaktif modern:
1. **CMS Posts**: Pengelolaan artikel blog dan konten halaman utama.
2. **Color Palette**: Pengelolaan tema warna sistem.
3. **Mentors**: Pengelolaan biodata, spesialisasi, dan status mentor.
4. **Programs**: Pengelolaan program pelatihan, harga, jenjang, dan kurikulum.
5. **Users**: Pengelolaan akun pengguna, peran (*role*), dan penetapan cabang (*branch*).

---

## Cara Menambah Data Baru
1. Masuk ke halaman admin yang relevan (misalnya **Mentors** atau **Programs**).
2. Klik tombol **"Add New [Nama Modul]"** yang terletak di kanan atas halaman.
3. Sebuah modal dialog akan muncul di tengah layar dengan efek transparansi modern (*glassmorphism*).
4. Isi seluruh kolom input yang wajib (*required*).
5. Klik **"Simpan"** untuk menyimpan data baru.

---

## Cara Mengubah / Mengedit Data
1. Cari baris data yang ingin diubah dalam tabel penampil data.
2. Di kolom paling kanan (Actions), klik tombol menu ikon titik tiga (**More Horizontal**).
3. Pilih opsi **"Edit"** atau **"Edit Profile"** / **"Edit Details"**.
4. Form modal dialog akan muncul dengan kolom-kolom yang sudah terisi otomatis oleh data saat ini.
5. Ubah bagian data yang diinginkan, kemudian klik **"Simpan"** untuk memperbarui data.

---

## Cara Menghapus / Menonaktifkan Data
1. Klik tombol menu ikon titik tiga (**More Horizontal**) pada baris data yang dituju.
2. Pilih opsi **"Delete"** atau **"Delete / Deactivate"**.
3. Sistem akan memunculkan konfirmasi dialog peramban untuk mencegah ketidaksengajaan.
4. Klik **"OK"** untuk menyetujui penghapusan/penonaktifan data.
