# Panduan Pengguna: Penahanan Saldo (Wallet Holds)
# Arkanin Management System (AMS)

Modul **Wallet Holds** digunakan oleh tim Keuangan (*Finance Operations*) untuk mengunci sementara sebagian dana pada dompet pengguna untuk keperluan jaminan garansi kelulusan, penanganan sengketa (*dispute*), atau proteksi proses refund.

---

## 1. Menahan Saldo Pengguna (Create Hold)

1. Buka menu **Finance** $\rightarrow$ **Transactions & Wallet** (Tab *Hold Balances*).
2. Klik tombol **+ Tahan Saldo (Hold Balance)**.
3. Cari akun pengguna target.
4. Masukkan nominal yang akan ditahan (misal Rp 250.000).
5. Tuliskan alasan penahanan dan syarat pelepasan (*release condition*).
6. Klik **Konfirmasi Penahanan**.
7. Saldo aktif pengguna akan berkurang dan berpindah ke status saldo tertahan (*pending balance*).

---

## 2. Melepas atau Memotong Dana Tertahan

- **Lepas Saldo (Release)**: Jika syarat pelepasan telah terpenuhi (misal masa garansi 14 hari selesai tanpa klaim), klik tombol **Lepas Saldo**. Dana langsung kembali ke saldo aktif siswa.
- **Potong Permanen (Forfeit)**: Jika sengketa memutuskan pemotongan dana (misal klaim disetujui untuk pengembalian ke institusi), klik tombol **Forfeit Saldo**. Dana tertahan akan dihapus dari dompet pengguna secara permanen.
